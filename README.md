# 💎 XStore — Զարդերի Առցանց Խանութ

**XStore**-ը զարդերի e-commerce կայք է, որտեղ օգտատերերը կարող են դիտել, ֆիլտրել և գնել ապրանքներ հարմար ու գեղեցիկ ինտերֆեյսով։

🌐 **Կայք՝** [xstore-jewelry-demo-6x6q.vercel.app](https://xstore-jewelry-demo-6x6q.vercel.app)
📂 **Կոդ՝** [github.com/Narek-Momchyan/XSTORE-JEWELRY-DEMO](https://github.com/Narek-Momchyan/XSTORE-JEWELRY-DEMO)

---

## 💡 Ի՞նչ է անում հավելվածը

- 🔍 **Ֆիլտրում** — ապրանքների զտում ըստ գնի, վարկանիշի և կատեգորիայի
- 🛍️ **Գնման զամբյուղ** — ապրանքների ավելացում, հեռացում, քանակի կառավարում
- 💳 **Checkout** — գնումների ամբողջական հոսք մինչև վճարում
- 🏷️ **Զեղչային համակարգ** — 3 և ավելի ապրանք գնելիս ավտոմատ զեղչ է կիրառվում
- 📄 **Ապրանքի էջ** — յուրաքանչյուր ապրանք ունի առանձին մանրամասն էջ
- ✉️ **Կապ** — EmailJS-ի միջոցով հաղորդագրություն ուղարկելու հնարավորություն
- 🎞️ **Անիմացիաներ** — Framer Motion-ով հարթ անցումներ և էֆեկտներ

---

## 🛠️ Օգտագործված տեխնոլոգիաներ

| | Տեխնոլոգիա | Նպատակ |
|---|---|---|
| **Framework** | Next.js 16 + React 19 | Արագ, SEO-friendly հավելված |
| **Անիմացիաներ** | Framer Motion | Գեղեցիկ UI անցումներ |
| **Slider** | Swiper | Ապրանքների կառուսել |
| **HTTP** | Axios | API հարցումներ |
| **Backend (demo)** | JSON Server | Mock REST API տվյալների համար |
| **Էլ. փոստ** | EmailJS | Backend-ի կարիք չունեցող form submit |
| **Deployment** | Vercel | Ավտոմատ deploy |

---

## 👨‍💻 Ի՞նչ սովորեցի այս պրոյեկտից

- E-commerce հավելվածի ամբողջական կառուցում React Context-ով
- Ֆիլտրման և տեսակավորման տրամաբանության ստեղծում
- Framer Motion-ի կիրառում UI-ն կենդանի դարձնելու համար
- Կարևոր բիզնես տրամաբանության ինտեգրում — ավտոմատ զեղչային համակարգ
- JSON Server-ով mock backend-ի օգտագործում արագ prototype-ի համար
- EmailJS-ի ինտեգրում՝ backend-ի կարիք չունեցող contact form-ի համար

## 🚀 Տեղական գործարկում

```bash
git clone https://github.com/Narek-Momchyan/XSTORE-JEWELRY-DEMO.git
cd XSTORE-JEWELRY-DEMO
npm install
npm run dev
```

Հավելվածը կբացվի՝ [http://localhost:3000](http://localhost:3000)
JSON Server-ը կգործի՝ [http://localhost:8080](http://localhost:8080)
